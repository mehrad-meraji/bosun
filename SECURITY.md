# Security

Bosun holds the Docker socket, so a bug in it can matter. Please report security
problems in private, not in a public issue.

Report one here: https://github.com/mehrad-meraji/bosun/security/advisories/new

Say what you found, how to make it happen, and what an attacker gets. You will get a reply
within a week.

Only the newest version on `main` gets security fixes.
